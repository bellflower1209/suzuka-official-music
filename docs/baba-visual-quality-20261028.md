# 第13世界 ビジュアル品質修正

基準main：`e3e0c9d0f22c5517a81698b6a2b2d29b88e8851d`。運営者のiPhone実機報告を受けた修正。

## 画像の縦伸び

公式画像の正本は1280×720（16:9）のJPEG。上段ポスターには`height:auto`があった一方、下段の紹介画像はHTMLの`height="720"`と`max-width:100%`だけが適用され、既定の`object-fit:fill`で約335×720（390px幅）に変形していた。前回の表示検証は下段の描画比率を測定していなかった。

両方に専用クラスを設定し、BABA NOVAに限定した`width:100%;height:auto;aspect-ratio:16/9;object-fit:contain`を適用。親pictureも固定高や引き伸ばしを持たせない。公式画像のファイル本体・顔・文字・構図は変更しない。

## 背景素材の承認と制作

運営者から「夜景背景の新規制作を承認する（人物・文字なし）」の明示承認を取得。image_genで横長と縦長の架空の江戸・吉原風夜景を制作した。人物・文字・ロゴを含めず、木造建築、格子、提灯、夜桜、路面の反射、前景から奥の門への遠近感を確認。横長画像の提灯にあった文字状の微小な印も除去した。公式の人物画像を生成・編集の入力には使用していない。

実在する街の記録写真や既存公式素材とは表記しない。由来・承認・元画像の寸法とハッシュ・派生画像を`site-content/baba-nova/backgrounds.json`で管理し、ページの背景説明も更新する。

スマートフォンは縦長専用画像を選択。横長768/1280/1600pxと縦長768pxをWebP/AVIFで用意。大きな図形の提灯を撤去し、控えめな花びら・光と既存のカメラ制御を保持する。背景元PNGは開発用正本として保管し、Pagesには圧縮派生画像だけを追加する。旧SVGは復元可能性を保つためインベントリーに保持するが、描画には使わない。

## 保護と検証

13世界・13組・104作品、公式画像、BGM、既存12世界の背景・本文・楽曲・演出を維持する。音声JS、Service Worker、認証、バックエンドは変更しない。CSSのキャッシュ識別子を更新し、既存キャッシュでも修正CSSを取得できるようにする。

既存69項目、追加3検査、従来の第13世界7検査、背景正本・派生画像の照合、Chrome/WebKitの390/768/1440pxで上段・下段の描画比率を測定する。390/768pxはisMobile・タッチ・DPR3を設定する。画像decode完了を待ち、背景の選択、顔・文字の比率、横はみ出し、扉・戻る・モーションOFF・音声操作を確認する。実機iPhoneの修正後確認とは区別する。

既存の音源再生遅延は今回の修正対象外で、未解決として維持する。Terminalの未コミット36件を変更しない。

## 再生成と復旧

公式画像の寸法・縦横比を推測で変更しない。背景更新は承認済みの正本PNGだけを用い、`prepare_baba_backgrounds.py --write`→`--check`で派生画像を作成・照合する。続いて`build_baba_nova_world.py --write`→`--check`、`verify_public_release.py`、比率テストと必須CIを実行する。

復旧はこの修正のマージコミットを通常のrevert PRで戻し、Pagesと正式ドメインを照合する。既存12世界・音源バックエンドに変更がないため、音源やR2オブジェクトを削除・再登録しない。
